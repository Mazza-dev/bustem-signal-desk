# Bustem Brand Report Queue

A working queue for public reports about fake stores, copied products, and brand impersonation. Built by Tolani Lambe as a sample of the GTM work I could own at Bustem. [See how I would run it](WORKFLOW.md).

Open `index.html` through a local server or use the hosted page. Add a public report, review its date and evidence, and export a CSV. The example cases show the checks. They are not a list of confirmed available prospects.

## Why this workflow

Bustem already offers a free brand scan. I would use public reports to find brands with a current problem, check whether the brand is a fit, and avoid reaching out when the issue is old, resolved, or already being handled by Bustem.

## What works

- Add a public report with its URL, date, brand, issue, and current status.
- Rank entries using visible rules.
- Hold old, resolved, or already engaged cases for review.
- Save the queue locally and export a CSV.

## What a live version needs

Connect the team's approved monitoring tools and CRM, verify each case, and check account ownership before outreach. Track reviewed reports, scans booked, conversations, and customers. The demo does not send messages, file claims, or estimate revenue.

## Example cases

Each example links to the public brand notice or post that supports it. A person should recheck the current status before contacting anyone.
